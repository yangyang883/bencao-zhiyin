# 本草知音设备版

树莓派 5 上的舌象展示与本地推理项目。当前实机部署的是 Next.js 页面、IMX708 摄像头采集、YOLOv8n ONNX 十类舌象外观检测，以及基于检测结果的规则建议。页面和模型服务分别监听本机 `127.0.0.1:3100`、`127.0.0.1:8765`。

**当前边界：**本地千问（文字与视觉）、实机语音输入/播报、云端千问与本地模型的自动切换均未完成整机验收。代码中有相关接口，不代表这些能力已部署。YOLO 输出是外观候选，不能用于疾病诊断。

- [安装和运行](INSTALL.md)
- [离线服务与静音验收](offline/README.md)
- [云端配置示例](.env.example)；密钥只放本机环境变量，不要提交到仓库。

源码不包含操作系统、Node/Python 运行环境或本地千问权重。`offline/models/tongue-yolov8n.onnx` 是当前舌象模型。
