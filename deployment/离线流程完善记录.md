# 离线流程完善

1. 拍照或选图后先进入原图预览，确认清晰度、舌缘和当前分析方式，再开始分析；可重新拍照或选图。
2. 等待页显示实际等待秒数，取消按钮会中断请求，不保存取消后的结果；移除了没有服务端依据的“步骤完成”勾选动画。
3. 本地模型报告在列表和详情统一标记“待核对”，不把试验结果标成健康异常。历史报告原始数据不改写。
4. 文件读取只在成功时提交，取消或卸载会终止读取；同一图片允许重新选择。相册按钮补充了可访问名称。

验证：软件测试、类型检查通过；新增本地报告状态断言。页面操作仍需人工验收：选图→预览→确认→结果→报告；分析中取消后不应生成新报告。当前工具的浏览器访问限制尚未解除，未声称完成这一轮界面自动化验收。

这些修改改善操作和结果表达，不代表模型识别准确率提高，也没有同步到 Jetson。专业准确率仍需专家标注数据和独立测试集评估。
