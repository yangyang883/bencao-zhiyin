# 电脑离线进度与四人交接

电脑网页：http://127.0.0.1:3100/home 。本地分类服务：127.0.0.1:8765。
当前已启动，默认离线。再次启动可在项目目录执行 `powershell -File .\启动电脑离线版.ps1`。
测试图片在 offline/samples，上传图片即可分析。电脑和设备各自保存浏览器报告，不会自动同步。

## 已实测通过

- npm test、npm run typecheck。
- Python 图片校验与报告测试两项；设备检查脚本的自测。
- 真实本机接口：三张样本分类、本地知识问答、知识库统计、坏图片拒绝、离线录音识别拒绝。
- 修复电脑启动兼容问题：Windows 启动器先加载 optree，再加载 torch，避免已有库的加载顺序崩溃。没有改设备的推理逻辑或全局 Python 安装。

复测：`python offline/run_pc.py --test`，以及 `python offline/check_runtime.py --samples offline/samples --core-only`。
后一个命令明确跳过本机未安装的通义模型和 WAV 语音引擎，不代表这两项测试通过。当前测试没有关闭电脑网络；默认离线接口与不回退云端的自动测试通过。
