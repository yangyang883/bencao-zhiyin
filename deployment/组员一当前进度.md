## 已准备

同目录 `check-hardware.py` 使用 Python 3 标准库，不需要安装第三方库。在 Jetson 上运行：

```bash
python3 check-hardware.py
```

它检查系统、USB识别、录音与播放设备列表、摄像头节点、串口节点、Docker服务和启动设置、容器状态及网页接口，并在运行目录生成 JSON 报告。不会修改系统或重启服务。没有安装某个检查工具或权限不足时会记录失败，不能据此直接判定硬件损坏。

## 日后连接设备时

1. 确认 Jetson 开机、供电稳定，网线仍连接当前电脑。
2. 告知已经接上的设备：摄像头、音箱、麦克风、ESP32、灯、按钮、距离传感器。
3. 若 SSH 仍中断，在设备本机终端查看 `hostname -I` 和 `systemctl status ssh --no-pager`，提供当前地址和服务状态；无需提供密码到文档中。
4. 连接恢复后再检查实际画面、录音、扬声器声音和完整操作流程。

USB 摄像头和 USB 音频设备可以按各自接口连接。ESP32、灯、按钮和测距模块的接线需要先确认型号与供电规格，当前没有足够信息给出具体引脚图。
